# Tranquil Drag & Drop

**Drag-to-save bookmarks and undoable file operations for the [Tranquil Studio](https://github.com/tranquillabs/tranquil-client) tree view.**

> Part of the Tranquil toolkit, in early developer preview.

## What it does

- Drag any editor or browser tab onto the Project Pane to save it — browser tabs become collision-safe `.url` files.
- Adds undo for tree-view file operations (rename, delete, move).
- Hold ⌥/⌘ while dragging to copy instead of move.
